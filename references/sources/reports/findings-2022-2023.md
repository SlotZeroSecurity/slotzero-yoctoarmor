## Corpus accounting

- **Input:** 30 user-supplied PDF audit reports: the original 20-report batch, five follow-ups, and five Aurora/Rainbow Bridge historical reports added in September 2026.
- **Source entries preserved:** 376, including security findings, recommendations, notes, and quality observations.
- **Prior-corpus duplicates:** 34 entries: 17 from the AuditOne Aurora NEAR Plugins report already represented by `2023-03-14-Aurora_NEARplugins.md`, plus all 17 Ref Exchange v3 entries that repeat the already ingested Ref Exchange ledger.
- **New source entries:** 342.
- **Deduplication rule:** merge only when the causal defect, violated invariant, attacker/control precondition, receipt phase, terminal harm, and fix class agree. Similar titles or recommendations are not enough.
- **Severity:** the source report's rating is provenance, not the rating for a future target.

The ledger retains every report entry. `Existing` pattern IDs were already present in the scanner; `New` IDs were added only after checking the existing catalog. Quality-only items remain searchable but do not count as vulnerabilities without material target harm.

## Deduplication outcome

### New canonical patterns

| Pattern | Why it is distinct | Source anchors |
|---|---|---|
| `NA-ASYNC-006` — Stale callback snapshot overwrites intervening state | A callback writes an old full object/rate/share snapshot after another receipt changed the live record; this differs from late reservation and missing compensation. | NearX ADV-00; PembRock failed-withdraw restore; XRef failed-unstake remint; Tonic stale state |
| `NA-ACCOUNT-001` — Global storage delta is charged to the wrong account | Growth may be paid, but attribution uses whole-contract `storage_usage` or another user's baseline. | Burrow liquidation and per-user storage; PembRock storage assertion |
| `NA-CRYPTO-001` — Ambiguous, non-canonical, or incomplete decoding changes authority or execution | The signed/validated representation differs from what is executed, or trailing bytes/case/delimiters admit a second meaning. | near-eth ADV-00; Sigma Prime NSS-06; Octopus appchain ID and receiver parsing |
| `NA-INTEGRATION-002` — Standard ABI or lifecycle semantics drift breaks interoperability | Method signature, export, payability, option type, or lifecycle deviates from the implemented NEP and causes material integration failure. | NameSky NEP-199; Mintbase NFT lifecycle; Ref/NEP observations |
| `NA-AUTH-005` — Initialization is public, repeatable, or binds unsafe first state | First-caller capture and unsafe initial role/config validation are a distinct reachability gate. | Tonic public initializer; constructor and role-conflict findings |
| `NA-ACCOUNT-003` — Accumulated value has no safe claim or recovery transition | Funds or rewards accrue correctly but no reachable terminal path can withdraw/recover them. | Ref DCL fees; NameSky mint fees; MetaPool treasury; Boost Farm beneficiary rewards |
| `NA-ACCOUNT-004` — Accrual or reward snapshot is not settled before mutation | Rate, weight, booster, position, or token state changes without first settling value under the old parameters. | PembRock accrual; XRef exchange rate; Boost Farm reward snapshots |
| `NA-ECON-001` — Asset identity, unit, or collateral type is confused | Accounting is internally consistent for the wrong asset, bucket, decimal, or collateral class. | Tonic collateral/order issues; DCL reference price; Octopus token metadata |
| `NA-ECON-003` — Public proof, reveal, or reward can be copied or frontrun | A public value-bearing submission is not bound to claimant/domain/round or protected by commit-reveal. | Sigma Prime bridge challenge finding |
